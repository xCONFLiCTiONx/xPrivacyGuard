# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues or discussions before a fix is available.

Use GitHub's private vulnerability reporting feature for this repository when available. Include the affected version or commit, Android version, device details that are safe to share, clear reproduction steps, and the potential impact. Remove private keys, WireGuard profiles, Zero Trust identifiers, access tokens, and personal DNS or filter-list data from reports.

If private vulnerability reporting is unavailable, contact the repository maintainer through a private channel listed on the maintainer's GitHub profile. Do not publish exploit details or proof-of-concept code that exposes users before coordinating disclosure.

## Scope

Security reports are especially relevant to VPN tunnel handling, packet parsing, DNS resolution, filter rule processing, configuration storage, and credential handling.

## Response

Reports will be reviewed as time permits. Please allow a reasonable period for investigation and remediation before public disclosure.
